# คู่มือเริ่มต้น: สื่อสารง่าย

ต้นแบบนี้มี 2 Skills สำหรับช่วยแสดงข้อความและฝึกสื่อสารตามความสมัครใจ รองรับภาษาไทย อังกฤษ และแบบสองภาษา ยังไม่ได้ทดสอบกับเด็กหรือผ่านการรับรองทางคลินิก

## เลือกวิธีใช้ตามอายุ

- ต่ำกว่า 13 ปี: ผู้ใหญ่เป็นผู้โต้ตอบกับ ChatGPT เด็กเลือกคำตอบผ่านวิธีสื่อสารเดิมได้ แล้วผู้ใหญ่พิมพ์ให้ ห้ามให้เด็กใช้บัญชีเอง ใช้บัตรฝึกแบบออฟไลน์ได้
- 13–17 ปี: ChatGPT ต้องได้รับความยินยอมจากผู้ปกครองก่อน โหมดฝึกเปิดโอกาสให้เลือกตอบเองตามกติกาของแพลตฟอร์มและแผนช่วยเหลือที่ตกลงกัน
- Claude: ผู้ใช้บริการต้องอายุอย่างน้อย 18 ปี ผู้ใหญ่ใช้เตรียมบัตรฝึกสำหรับทำออฟไลน์กับเด็กได้ ไม่ใช่การส่งบัญชีให้เด็กใช้
- 18 ปีขึ้นไป: เลือกใช้ทั้งสองแพลตฟอร์มตามสิทธิ์บัญชีและความต้องการของตนเอง

## ติดตั้ง Claude สำหรับผู้ใหญ่

1. สร้างไฟล์ด้วย `python3 scripts/build_release.py` หรือใช้ ZIP ที่อยู่ใน `dist/`
2. เปิดความสามารถ Code execution and file creation ตามคู่มือของ Claude
3. ไปที่ Customize → Skills → + Create skill → Upload a skill
4. อัปโหลด `claude-easy-communication-0.1.0.zip` และ `claude-communication-practice-0.1.0.zip` ทีละไฟล์ แล้วเปิดใช้งาน
5. เริ่มแชตใหม่และพิมพ์ “ช่วยฉันสื่อสาร” หรือ “ฝึกสื่อสาร” ถ้าเมนูไม่ตรงให้ตรวจคู่มือปัจจุบันและสิทธิ์ของบัญชี

## ติดตั้ง ChatGPT

แพ็กเกจ `openai-easy-communication-0.1.0.zip` เป็น plugin ที่มีสอง Skills ใช้สำหรับทดสอบหรือส่งผ่านช่องทาง plugin ที่บัญชีรองรับ ไม่ใช่ไฟล์แนบในแชตที่จะติดตั้งถาวรได้เอง

หากบัญชียังไม่รองรับการติดตั้ง ให้เปิด SKILL.md ของโหมดที่ต้องการ คัดลอกเฉพาะเนื้อหาหลังส่วน `---` ด้านบนไปเป็นคำแนะนำในแชตใหม่ แล้วส่งคำเริ่มต้น วิธีนี้เป็นการทดสอบคำแนะนำในแชตเดียว ไม่ใช่การติดตั้ง Skill และไม่รับประกันพฤติกรรมเหมือน plugin ต้องตรวจคำตอบก่อนใช้งานจริง

## ตั้งค่ากับผู้ใหญ่ครั้งแรก

ส่งเฉพาะข้อมูลที่จำเป็น เช่น “ใช้ ChatGPT ผู้เรียนอายุ 13–17 ปี ได้รับความยินยอมจากผู้ปกครองแล้ว ภาษาไทย ครั้งละ 2 ตัวเลือก อยากฝึกขอความช่วยเหลือ” ไม่ต้องส่งชื่อจริง วันเกิด โรงเรียน ประวัติการวินิจฉัย รูปเด็ก หรือเสียงเด็ก

ใช้ภาษาเดียวก่อน หากต้องการเปลี่ยนให้พิมพ์ `English`, `ไทย` หรือ `สองภาษา` ฝึกเองในที่นี้หมายถึงผู้เรียนเลือกจังหวะและคำตอบได้ ไม่ได้หมายถึงรับประกันว่าจะใช้ได้โดยไม่มีการช่วยเหลือหรือข้ามข้อกำหนดอายุ

## คำที่ใช้ควบคุม

| คำ | ผล |
|---|---|
| พัก | พัก ไม่มีโจทย์ใหม่ |
| หยุด | จบการโต้ตอบ |
| จบ | จบข้อความหรือรอบฝึกโดยไม่ต้องแต่งประโยคครบ |
| แก้ | แก้ข้อความที่กำลังสร้าง |
| ซ้ำ | แสดงข้อความหรือโจทย์ล่าสุดซ้ำ |
| ข้าม | ข้ามโจทย์ฝึก |
| ง่ายขึ้น | ลดจำนวนตัวเลือกหรือใช้ข้อความสั้นลง |

ตัวเลขเป็นข้อความให้พิมพ์ตอบ ไม่ใช่ปุ่มกด รูปหรือเสียงขึ้นอยู่กับความสามารถเดิมของแอป Skill ไม่สามารถเพิ่มกระดานรูปภาพ ปุ่มดับเบิ้ลคลิก หรือเปิดไมโครโฟนให้เอง

## บัตรฝึกออฟไลน์

ผู้ใหญ่เขียนหรือแสดงทีละบัตร เด็กใช้คำพูด ชี้ เขียน AAC หรือปฏิเสธได้ ตัวอย่าง: “สมมติว่าอยากได้น้ำ อยากบอกอย่างไร?” → “น้ำ” / “ขอน้ำ” / “คำของตัวเอง” เมื่อสื่อความหมายแล้วให้รับฟังได้ทันที ไม่ต้องให้ทวนหรือแต่งประโยคครบ หากต้องการน้ำจริงให้ช่วยสื่อสารเรื่องจริงก่อน ไม่ใช้ความต้องการจริงเป็นเงื่อนไขผ่านแบบฝึก

ใช้อุปกรณ์ AAC เดิมต่อได้เสมอ หยุดเมื่อผู้เรียนไม่ต้องการฝึก และให้ผู้เรียนมีส่วนออกแบบคำ ตัวเลือก และเป้าหมายด้วย
