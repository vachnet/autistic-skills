# Optional language models

These are original examples, not a validated vocabulary list. Use the person's chosen words; do not assume all autistic people need the same vocabulary. Show only the relevant line in the selected language. Use paired lines only if bilingual output is requested.

| Function | ไทย | English |
|---|---|---|
| Request | ขอน้ำ | I want water. |
| Refuse | ไม่ต้องการ | I don't want that. |
| Stop touch | ไม่อยากให้จับตัว | I don't want to be touched. |
| Ask for help | ช่วยหน่อย | I need help. |
| Pause | ขอพัก | I need a break. |
| Sensory need | เสียงดังเกินไป | It is too loud. |
| Ask location | ห้องน้ำอยู่ไหน | Where is the toilet? |
| Clarify | ไม่เข้าใจ | I don't understand. |
| Repair | ไม่ใช่ หมายถึง… | No, I mean… |
| Ask time | ไปเมื่อไร | When are we going? |
| Comment | ชอบเพลงนี้ | I like this song. |
| Decline exercise | ไม่อยากฝึก | I don't want to practice. |

If someone types `ไม่เอา`, reflect that refusal rather than replacing it with a longer phrase. Do not soften a boundary. If they type `ตึกกินข้าว`, allow that wording; ask about meaning only if necessary for the requested task.

For optional sentence building, permit an early finish after any meaningful selection. A draft could progress `ขอ` → `ขอน้ำ` → `ขอน้ำเย็น`; it need not start with a subject. Questions and negation remain available at every stage.
